## 🌐 Introduction to Programming Languages

Explore how programming languages express ideas and solve problems.

Each language introduction will cover:

- **Purpose** — What the language is commonly used for
- **Setup** — How to prepare the development environment
- **Syntax** — How basic programs are written
- **Execution** — How source code becomes a running program
- **Practice** — Small examples and beginner projects

The focus is on understanding core concepts and recognizing their similarities and differences across languages.

## 🧪 Cisco Packet Tracer Labs

Put networking concepts into practice through simulated networks.

### Planned Labs

- [ ] Explore the interface and available devices
- [ ] Build a basic network topology
- [ ] Connect devices using appropriate cables
- [ ] Assign IP addresses to end devices
- [ ] Test connectivity with `ping`
- [ ] Configure basic router and switch settings
- [ ] Connect different networks using static routes
- [ ] Create VLANs and configure trunk links
- [ ] Configure inter-VLAN routing
- [ ] Configure DHCP
- [ ] Explore dynamic routing with OSPF
- [ ] Configure NAT and PAT
- [ ] Apply basic access control lists
- [ ] Inspect packet flow in Simulation Mode
- [ ] Diagnose and fix intentionally broken networks

### Lab Documentation

Each lab will aim to include:

1. **Objective** — What the exercise teaches
2. **Topology** — Devices and connections
3. **Addressing Table** — IP addresses, subnet masks, and gateways
4. **Configuration Steps** — Commands and explanations
5. **Verification** — Tests and expected results
6. **Troubleshooting Notes** — Common mistakes and fixes

Where available, labs will include a **Packet Tracer project file (`.pkt`)** for practice.

## 📝 Learning Approach

The notes aim to answer:

- **What is it?**
- **How does it work?**
- **Why does it matter?**
- **Where is it used?**
- **How can I practice it?**

Whenever useful, explanations will be supported by **examples, diagrams, commands, exercises, and references**.
