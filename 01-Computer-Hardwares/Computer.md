# 🖥️ What Is a Computer?

> A computer is a programmable system that receives input, processes data, stores information, and produces output.

## 📖 Definition of a Computer

A **computer** is an electronic device that executes programmed instructions to process data.

These instructions allow it to perform calculations, make logical comparisons, manage information, and control other devices.

Computers take many forms, including desktops, laptops, smartphones, servers, and embedded systems.

### Four Basic Functions

| Function | Purpose | Example |
| :--- | :--- | :--- |
| **Input** | Receives data or instructions | Typing on a keyboard |
| **Processing** | Performs operations on data | Calculating a total |
| **Storage** | Retains data and programs | Saving a document |
| **Output** | Communicates results | Displaying text on a screen |

> 💡 A computer follows instructions. Its usefulness depends on the programs it runs, the data it receives, and the hardware available.

## 🕰️ History of Computers

| Period | Development |
| :--- | :--- |
| **Early Calculating Tools** | Devices such as the abacus helped people perform arithmetic. |
| **Mechanical Computing** | Mechanical calculators and programmable-machine designs contributed to the development of computing. |
| **Early Electronic Computing** | Systems such as ENIAC demonstrated large-scale electronic calculation. |
| **Commercial Computing** | Systems such as UNIVAC I helped bring electronic data processing into organizations. |
| **Microprocessor Era** | Integrating CPU functions onto a chip helped make smaller, more affordable computers practical. |
| **Personal and Networked Computing** | Personal computers and computer networks expanded access to digital tools. |
| **Mobile and Embedded Computing** | Computing became integrated into portable devices, appliances, vehicles, and industrial equipment. |

Computer development involves advances in **hardware, software, manufacturing, and communication technologies**.

## ⚙️ How a Computer Works

A computer combines physical components with instructions that tell those components what to do.

A simplified workflow is:

```text
Input → Processing → Output
             ↕
       Memory / Storage
```

### Example: Writing and Saving a Document

1. The keyboard sends **input** when you type.
2. The application and operating system process the input.
3. The **CPU** executes instructions, using registers, caches, and RAM.
4. The graphics system prepares the document for display.
5. The screen presents the **output**.
6. Saving the document writes its data to **persistent storage**, such as an SSD.

These operations overlap and repeat while you use the computer.

## 🧩 Main Hardware Components

| Component | Role |
| :--- | :--- |
| **CPU** | Executes instructions and performs general-purpose computation |
| **RAM** | Temporarily holds active programs and data |
| **Storage** | Retains programs and files without continuous power |
| **Motherboard** | Provides connections and supporting circuitry |
| **GPU** | Handles graphics and suitable parallel workloads |
| **Power Supply** | Supplies electrical power in the form required by the system |
| **Networking Hardware** | Enables communication with other devices |

Components may be separate, integrated into one package, or soldered onto a board.

### Memory vs. Storage

- **RAM** provides temporary working space for active tasks.
- **Persistent storage**, such as SSDs and HDDs, retains saved data when power is removed.

> 📌 Keeping a document open in memory does not replace saving it to persistent storage.

## 💿 Hardware, Software, and Firmware

### Hardware

The physical parts of a computer.

**Examples:** CPU, RAM, motherboard, keyboard, and storage devices.

### Software

Programs and instructions executed by the computer.

**Examples:** Operating systems, browsers, text editors, and games.

### Firmware

Software stored in a device that supports hardware initialization or device operation.

**Examples:** UEFI system firmware and firmware inside storage or networking devices.

### The Operating System

An **operating system** manages resources and provides services for applications.

Typical responsibilities include:

- Scheduling processor time
- Managing memory
- Organizing files
- Controlling access to devices
- Enforcing permissions
- Supporting networking

Not every computer requires a general-purpose operating system. Some embedded systems run dedicated software directly.

## 🗂️ Types of Computers

These categories describe different purposes and can overlap.

| Type | Characteristics and Uses |
| :--- | :--- |
| **Personal Computer** | Designed for individual use, including desktop and laptop systems |
| **Workstation** | Intended for demanding professional workloads such as engineering, development, and content creation |
| **Server** | Provides services or resources to clients |
| **Mainframe** | Designed for high-volume processing, reliability, and large numbers of concurrent transactions |
| **Supercomputer** | Combines substantial computing resources for demanding scientific and numerical workloads |
| **Mobile Computer** | Portable systems such as smartphones and tablets |
| **Embedded Computer** | Performs dedicated functions within another device or system |

### A Note About Servers

A server is defined by the **service it provides**, rather than only by its physical shape.

A personal computer can act as a server, while dedicated server hardware supports particular capacity and reliability requirements.

## 🔢 How Computers Represent Data

Computers commonly represent data using **binary digits**, called **bits**.

A bit has two possible values:

```text
0 or 1
```

A **byte** consists of eight bits.

Patterns of bits can represent:

- Numbers
- Text
- Images
- Audio
- Video
- Program instructions

The meaning depends on the encoding or data format being used.

> 💡 The same underlying hardware can process many kinds of information because software defines how the encoded data is interpreted.

## 📡 Computers and Networks

A **computer network** connects devices so they can exchange data and share services.

Communication follows **protocols**: agreed rules for message formats and behavior.

| Protocol | Basic Role |
| :--- | :--- |
| **IP** | Provides addressing and packet delivery across networks |
| **TCP** | Provides a reliable, ordered byte stream between applications |
| **HTTP** | Defines requests and responses used by web applications |
| **HTTPS** | Uses HTTP over a connection protected by TLS |
| **FTP** | Transfers files; its basic form does not encrypt traffic |
| **SMTP** | Transfers email between clients and servers or between mail servers |
| **IMAP / POP3** | Allow email clients to access messages |
| **DNS** | Resolves queries for domain-name records, including address records |
| **DHCP** | Supplies network configuration, such as IP address leases |

**TCP/IP** refers to a family of networking protocols, rather than a single protocol.

Networking devices, addressing, protocols, and practical labs are covered in the **Computer Networks** section.

## ⚖️ What Determines Computer Performance?

Overall performance depends on how well the system fits its workload.

Important factors include:

- **CPU capabilities**
- **Available RAM**
- **Storage performance**
- **GPU capabilities**
- **Network performance**
- **Power and cooling**
- **Software efficiency**

A limiting resource is often called a **bottleneck**.

For example, additional CPU cores may not improve a task that is waiting for slow storage.

## ✅ Key Takeaways

- A computer receives input, processes data, stores information, and produces output.
- Hardware, software, and firmware work together.
- RAM and persistent storage serve different purposes.
- Computers include much more than desktops and laptops.
- Networks allow computers to exchange data and provide shared services.
- Performance depends on the workload and the system as a whole.
